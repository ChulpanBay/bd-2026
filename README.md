## Проект "EduCore"
 Предметная область: онлайн-образование. Система охватывает процессы создания учебных курсов, регистрации студентов и отслеживания их успеваемости.
 Решает проблему разрозненности учебных материалов и отсутствия централизованного контроля прогресса студентов. Позволяет преподавателям создавать структурированные курсы, а студентам - записываться на них и получать оценки за выполненные задания.
